# V2 assets implementation plan

> **For agentic workers:** Use superpowers:executing-plans in this session, following the repository workflow. Review uses one independent reviewer before PR.

**Goal:** Produce reviewable, bundled v2 cats, accessories, furniture and four layered rooms without changing game rules or migrating the home early.

**Architecture:** Original SVG parts generated deterministically with Python, loaded through the existing SVG subset renderer. A shared Canvas rig composes all nine cats in home and puzzle directions; accessory anchors live in head space. No raster atlas or per-frame cache. Gallery is a separate development route.

**Tech stack:** Flutter/Dart Canvas, existing SvgTemplate, Python standard library.

Design authority: approved `docs/design-v2/SPEC.md` and `VISUAL.md`; reference A. Bos remains black/white tuxedo with blaze; Kembang remains dark tortoiseshell. No catalogue ID, price, save format or simulator changes. Vector is selected for crisp small sprites, separate layers and bounded storage; inspect output against A and report the lack of raster paper grain rather than claiming an identical painting.

## 1. Source package and rig

- [ ] Create `tool/art_v2/generate.py`: generate SVG parts and `assets/art/v2/manifest.json`, deterministic `--check`, ZIP/decoded raster accounting. Use catalogue IDs, 128-square cat canvas with safe hat margin; head-space accessory pivots; 390-square room layers; 128-square furniture back/front masks and interaction points.
- [ ] Create `lib/game/render/v2/art_pack.dart`: load manifest/files using an injectable AssetBundle; reject missing/invalid assets. Keep a finite per-pack map of drawings; no global animated variant cache.
- [ ] Create `lib/game/render/v2/cat_rig.dart`: idle/blink, eight-frame four-direction walk, sit/sleep/eat/play/brush/pet/happy/startled/tired and Oyen box/drop/chase/fish/win/bored; shared front/side/back parts, explicit right mirror. Use head-space transforms for all 16 accessories, static time for reduced motion.
- [ ] Bundle directories in `pubspec.yaml`. Run `python tool/art_v2/generate.py` then `--check`.

## 2. Gallery and review sheets

- [ ] Create `lib/gallery/gallery_v2_screen.dart`; add `/galeri/aset-v2` route and gallery link. Select cat, accessory, pose, direction, pause and scrub phase; view portraits, all furniture masks and four layered rooms. Stop ticker for reduced motion/background.
- [ ] Create `test/game/render/v2_art_test.dart`: load real bundled files, validate full catalogue coverage, render matrix bounds and head-space anchors, distinguish back/profile, bounded drawings after animation stress. Write transparent contact sheets and area previews to `docs/design-v2/assets/` through an explicit export flag.
- [ ] Create `test/gallery/gallery_v2_test.dart`: controls, loading failure/retry, reduced motion, small viewport/text scaling. Run `flutter test test/game/render/v2_art_test.dart test/gallery/gallery_v2_test.dart`.
- [ ] Inspect actual rendered PNGs, correct overlap/clipping/identity issues. Record bundle bytes, ZIP bytes, process RSS before/after load and stress, and CPU paint timing. Host measurements do not replace device frame/raster profiling in step 13.

## 3. Verification and handoff

- [ ] Update `assets/art/v2/README.md`, license/provenance, `docs/design-v2/assets/REVIEW.md`, `DESIGN_NOTES.md`, GDD/CLAUDE structure and roadmap status only when completion criteria hold. Record visual deviations and device limitations.
- [ ] Independent code review, address findings, run `dart format lib test`, `flutter analyze`, `python tool/translations/make_review.py --check`, `flutter test`, generator `--check`.
- [ ] Commit, push feature branch and create Indonesian PR against main. Leave merge to owner.
