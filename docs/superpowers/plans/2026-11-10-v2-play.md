# Langkah 7 ? Area Bermain

Basis main setelah PR #45. Desain mengikuti SPEC v2 yang telah disetujui:
kapasitas dua, satu bermain + satu menunggu, bola dasar gratis; main 8 detik,
+10 Senang per 30 menit, otomatis bila Senang <70. Hadiah tetap 10/hari/kucing.
Pelaksanaan langsung di sesi utama sesuai CLAUDE.md.

- [x] Baseline pub get, analyze dan seluruh test.
- [x] Proyeksi PlayState: kesiapan/cooldown waktu efektif, pemakai, mainan dan antrean scheduler; satu pemilihan mainan bersama model/render.
- [x] Latar ilustrasi selaras rumah, fasilitas mainan interaktif, satu prop sesuai kegiatan; posisi main/tunggu dan lintasan aman, kurangi gerak.
- [x] Panel dan sheet ajakan/batal, kebutuhan, pemakai dan aturan; empat ARB dan review terjemahan.
- [x] Test otomatis/ajakan, kuota lintas mainan, penuh, antrean, interrupt, hadiah, pause/reload/retry dan jam mundur.
- [x] Render normal/kecil/teks besar empat bahasa; review independen dan perbaikan.
- [x] Format, analyze, seluruh test, terjemahan dan APK; dokumentasi, commit, push dan PR.

Tidak mengubah skema simpanan, ekonomi atau aturan puzzle. Pemilihan mainan
mengikuti urutan katalog dari mainan terpasang, lalu bola gratis; fasilitas yang
sudah dipesan kegiatan aktif dipertahankan sampai selesai atau dibatalkan aman.

Hasil: analyze bersih; 2.948 test lulus / 135 skip; 106 test terarah lulus;
format 272 file tanpa perubahan, terjemahan/generator sesuai dan APK debug
berhasil. Review independen menemukan target mainan bertumpuk dengan kaki;
diperbaiki dan review ulang bersih. Regresi area kosong tetap dipertahankan.
